# PM Runs

Thư mục chứa run-state của các PM runs (mỗi run một thư mục con theo dạng `YYYY-MM-DD-<tên-run>/`).

Cấu trúc gợi ý cho mỗi run:

| File             | Nội dung                |
| :--------------- | :---------------------- |
| `brief.md`       | Yêu cầu đầu vào         |
| `outline.md`     | Dàn ý / phạm vi         |
| `run-plan.md`    | Kế hoạch thực thi       |
| `cost.md`        | Chi phí (token/time)    |
| `verdict.md`     | Kết quả đánh giá        |
| `escalations.md` | Các vấn đề cần escalate |

_(Chưa có run nào.)_
